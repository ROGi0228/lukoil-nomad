Критерий оценки

Вручную — бот только собирает вложения (доказательства), баллы за каждую команду проставляются на странице задания после сдачи. Глобальная миссия — рассылается один раз без кнопки «Сдать», команде ежедневно приходит напоминание, баллы проставляет админ здесь же в конце (после дедлайна).

Когда отправлять

Задание не уйдёт по расписанию — координатор запускает его кнопкой «Отправить сейчас» на странице задания, когда понадобится на месте.

Каждая команда получит это задание через указанное время после того, как САМА выполнит задание-триггер.

Для заданий «после другого задания» дедлайн, если не отмечено «Без дедлайна», нужно указывать датой ниже — иначе дедлайна не будет.

Не нужно заполнять, если отмечено «Задание дня» или «Без дедлайна».

Изменения не затрагивают уже отправленные сообщения — только дальнейшее поведение (напоминания, штраф, будущие рассылки по триггеру). Чтобы отозвать уже отправленное сообщение, используйте «Удалить рассылку» на странице задания.
